# Reverse task: Ы-Банк

Учебный проект с двумя вариантами интерфейса:
- консольное приложение на C (`bank_reverse_task.c`)
- графический веб-интерфейс (`bank_gui.html` + `bank_gui.css` + `bank_gui.js`)

## Функционал
- Перевод
- Пополнить
- Сколько денег на счету
- История операций

## Сборка C-версии
### Linux binary
```bash
make linux
```
или напрямую:
```bash
gcc -std=c11 -O2 -Wall -Wextra -pedantic bank_reverse_task.c -o ybank_task
```

### Windows `.exe`
```bash
make win-exe
```

Альтернатива:
```bash
./build_windows_exe.sh
```

> Для реального `.exe` нужен MinGW-w64 (`x86_64-w64-mingw32-gcc`).

## Запуск
```bash
./ybank_task
```

## Веб-интерфейс
Откройте `bank_gui.html` в браузере.

Или через локальный сервер:
```bash
python3 -m http.server 8080
```
и затем перейдите на `http://localhost:8080/bank_gui.html`.

## Условие секрета
Секрет открывается, если одновременно выполняются условия:
- баланс не меньше `1_000_000_000`
- перевод не меньше `1_000_000_000`
- перевод на номер `8925553525`

Флаг хранится в закодированном виде и декодируется только в runtime.

> Только для CTF/обучения. Реальные несанкционированные операции с деньгами незаконны.
