# Reverse task: Ы-Банк

Главная цель теперь: **Windows `.exe` с графическим интерфейсом (не CLI и не WEB)**.
GUI реализован на WinAPI в Unicode (`wWinMain`, wide-строки), чтобы не было «кракозябр» в русском тексте.
Визуальный стиль сделан в формате мобильного банковского интерфейса (как на референсе с телефоном/диалогами).

## Что есть в проекте
- `ybank_win_gui.c` — WinAPI GUI-приложение для сборки в `ybank_gui.exe`
- `bank_reverse_task.c` — старый CLI-вариант (оставлен как дополнительный)
- `bank_gui.html/css/js` — старый web-вариант (оставлен как дополнительный)

## Сборка GUI `.exe` (основной вариант)
```bash
make win-gui-exe
```

или напрямую скриптом:
```bash
./build_windows_exe.sh ybank_win_gui.c ybank_gui.exe
```

> Нужен MinGW-w64 (`x86_64-w64-mingw32-gcc`). Сборка GUI идет с флагами `-mwindows -municode`.

## Логика GUI-приложения
В графическом `.exe` есть:
- Пополнение
- Перевод
- Баланс
- История операций

Секрет открывается, если:
- баланс не меньше `1_000_000_000`
- перевод не меньше `1_000_000_000`
- перевод на номер `8925553525`

Флаг хранится в закодированном виде и декодируется только в runtime.

## Дополнительно (не основной путь)

```bash

```

и открыть `http://localhost:8080/bank_gui.html`.

> Только для CTF/обучения. Реальные несанкционированные операции с деньгами незаконны.
